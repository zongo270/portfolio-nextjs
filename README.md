# Serge-Antoine Keou Ketchiozo - Portfolio (Next.js 15 + Tailwind CSS)

Modern, performant, component-driven portfolio built with Next.js 15 App Router, React 18, Tailwind CSS, and Lucide Icons.

## 🚀 Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📦 Deployment Options

### Option 1: Vercel (Recommended - 1 Click)
1. Push this folder to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com) using your GitHub account.
3. Import the repository and click **Deploy**. Vercel will automatically build and deploy it with free global CDN and HTTPS.

### Option 2: GitHub Pages (Static Export)
This project has `output: 'export'` configured in `next.config.js`.
1. Run `npm run build`
2. Push the generated `out/` folder or configure a GitHub Action to deploy `out/` to GitHub Pages.
